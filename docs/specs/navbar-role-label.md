# Navbar role label

## Background

Each signed-in person has a role — either `admin` or `user`. The navigation bar
should make the current role visible at a glance, as a small label shown next to
the signed-in person's email.

## Requirements

- **R.1** — The navbar shows the role label for a signed-in admin
- **R.2** — The navbar shows the role label for a signed-in regular user
